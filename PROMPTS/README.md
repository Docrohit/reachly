# Reachly Prompt Library

Use these prompts to keep future AI/dev sessions consistent.

Recommended order:

1. `01_PROMPT_session_start.md`
2. Task-specific work
3. `05_PROMPT_session_end.md`
4. Write a session note in `sessions/`

Always read:

- `AGENTS.md`
- `product_theory.md`
- `business_goals.md`
- `docs/PERSONAL_REACHLY_STATUS.md`
- latest dated personal handoff in `sessions/`

Historical notes and `docs/archive/` do not define the current product or deploy target.
