## Combined product

This continues the original personal Reachly, retaining the later generation
upgrades from the copied snapshot. It owns the full input → research → generation
→ publishing → performance feedback loop. It is usable for any business,
project, or service, with separate workspaces under one personal sign-in.

- Independent Telegram sign-in and personal branding.
- Business workspaces with separate profiles, provider keys, platform accounts,
  drafts, history, schedules, and performance inputs.
- Studio accepts project information, SaaS2point0 output, research and analytics
  as saved input. Sourced online research uses the selected business's Gemini key.
- Generate text/image drafts separately from publishing. Explicit publishing
  uses the connected platform adapter; a draft's attempt is claimed once to avoid
  duplicate sends. Uncertain outcomes require a platform check.
- Original API/browser publishing, Medium and video paths are retained.
- Personal content-assets page restored alongside upgraded generation APIs,
  ideas, teleprompter, brand isolation, contributions, and performance signals.
- Analytics history accepts measured metrics and uses them in future prompts.
  Automatic metrics retrieval from platforms is not yet connected.
- SaaS2point0 input is pasted/imported as text; no direct API connector is claimed.
- Standalone context discovery stays in the explicitly chosen repo. Hosted
  businesses cannot read arbitrary operator repo files or global knowledge.
- Schedules start off, dry-run starts on, and business identity changes disable
  connected platform modes until the owner reviews them.
